Recolleat Build 44.2 — Android app install diagnostics

1. Export a JSON backup of your Recolleat collection, but DO NOT clear browser site data.
2. Extract the zip, upload all files to the GitHub REPOSITORY ROOT, on main. Do not upload the zip or an extra folder.
3. Commit and wait for Cloudflare Workers successful deployment; keep the current deploy command.
4. On the Android phone open https://recolleat.journaled.workers.dev/install-check.html and select Run checks again.
5. If any check fails, use Copy report and share the results. If checks pass but Install still fails, the issue may be Chrome's Android WebAPK installation service, not the website files. Do not resort to a shortcut or clear Chrome storage.

This build includes the original app, images, manifest, service worker, and a separate diagnostic page. No restaurant schema changes. It does not guarantee Chrome/Android can generate an installed WebAPK.
